# Premium Slaughter House Website

A professional website for a premium meat processing and delivery company, built with HTML, CSS, JavaScript, and Bootstrap.

## 📋 Project Overview

This is a fully functional website featuring:
- **Multiple Pages**: Home, About, Services, Products, Facilities, Gallery, Orders, and Contact
- **Responsive Design**: Mobile-friendly layout using Bootstrap
- **Rich Content**: Professional images and detailed information about services
- **Order System**: Interactive ordering functionality
- **Contact Forms**: Easy customer communication

## 📁 Project Structure

```
├── index.html              # Home page
├── about.html              # About Us
├── services.html           # Services offered
├── products.html           # Product catalog
├── facilities.html         # Company facilities
├── gallery.html            # Photo gallery
├── order.html              # Order system
├── contact.html            # Contact page
├── css/
│   └── style.css           # Main stylesheet
├── js/
│   └── script.js           # JavaScript functionality
└── images/                 # All images organized by page
```
